# 获取当前用户权限范围

获取当前登录用户的身份信息与数据权限范围。前端可根据返回的角色标识和范围集合，控制页面元素的显隐以及查询条件的默认值。

## 基本信息

| 项目 | 说明 |
|------|------|
| 请求路径 | `GET /api/auth/scope` |
| Content-Type | `application/json` |
| 鉴权要求 | 需要登录（`@ScopeAuthRequired`） |

## 请求参数

无。身份信息通过请求级上下文（`UserAuthContextHolder`）自动注入。

## 响应体

### 成功响应

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "userId": 1001,
    "talentCode": "EMP001",
    "talentName": "张三",
    "deptCode": 10,
    "posId": 5,
    "systemAdmin": false,
    "hr": true,
    "attendanceClerk": false,
    "departmentLeader": false,
    "groupLeader": false,
    "employee": false,
    "selfOnly": false,
    "deptScopes": [
      { "deptId": 10, "deptName": "研发部" },
      { "deptId": 20, "deptName": "产品部" }
    ],
    "groupScopes": [
      { "groupId": 1, "groupName": "考勤A组" }
    ],
    "posScopes": [5, 8],
    "areaScopes": ["AREA_001", "AREA_002"]
  }
}
```

### 字段说明

#### 身份信息

| 字段 | 类型 | 说明 |
|------|------|------|
| `userId` | Integer | 用户 ID |
| `talentCode` | String | 人员编码 |
| `talentName` | String | 人员姓名 |
| `deptCode` | Integer | 所属部门 ID |
| `posId` | Integer | 岗位 ID |

#### 角色标识

以下字段互斥，同一用户仅有一个为 `true`：

| 字段 | 类型 | 说明 |
|------|------|------|
| `systemAdmin` | Boolean | 系统管理员 |
| `hr` | Boolean | HR |
| `attendanceClerk` | Boolean | 考勤员 |
| `departmentLeader` | Boolean | 部门负责人 |
| `groupLeader` | Boolean | 组长 |
| `employee` | Boolean | 普通员工 |

#### 范围控制

| 字段 | 类型 | 说明 |
|------|------|------|
| `selfOnly` | Boolean | 是否仅能查看自身数据 |
| `deptScopes` | Array\<DeptScopeItem\> | 可管辖的部门列表（含部门名称） |
| `groupScopes` | Array\<GroupScopeItem\> | 可管辖的工作组列表（含工作组名称） |
| `posScopes` | Set\<Integer\> | 可管辖的岗位 ID 集合 |
| `areaScopes` | Set\<String\> | 可管辖的区域编码集合 |

#### DeptScopeItem

| 字段 | 类型 | 说明 |
|------|------|------|
| `deptId` | Integer | 部门 ID |
| `deptName` | String | 部门名称 |

#### GroupScopeItem

| 字段 | 类型 | 说明 |
|------|------|------|
| `groupId` | Integer | 工作组 ID |
| `groupName` | String | 工作组名称 |

### 失败响应

```json
{
  "code": 401,
  "message": "鉴权上下文不存在",
  "data": null
}
```

## 调用示例

```bash
curl -X GET http://localhost:8080/api/auth/scope \
  -H "Cookie: SESSION=xxx"
```

## 备注

- `deptScopes` 和 `groupScopes` 会在服务端将 ID 展开为带名称的对象，方便前端直接展示。
- `posScopes` 和 `areaScopes` 仅返回 ID/编码集合，不做名称展开。
- 该接口由 `@ScopeAuthRequired` 注解标记，请求必须经过鉴权拦截器并设置 `UserAuthContext`，否则返回 401。
