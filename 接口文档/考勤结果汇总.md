# 考勤结果汇总接口

基础路径：`/api/attendance/result`

统一返回结构：`ReturnInfo<T>`

公共规则：

| 规则 | 说明 |
|------|------|
| 请求方式 | 全部使用 `POST` |
| 参数方式 | 表单传参，不使用 `@RequestBody` |
| token | `tokenID` 通过 query 参数或请求头传入 |
| 响应结构 | 分页接口 `data` 直接返回列表，`total` 放总数，`currPage` 放当前页 |
| 权限范围 | 涉及员工范围的接口必须标注 `@ScopeAuthRequired` |
| 部门筛选 | 传入父部门时，必须按 `UserAuthContext.deptScopeTree` 展开子部门，再与 `deptScopes` 取交集 |
| 查询原则 | 只读已落表结果，不现场计算，不改计算逻辑 |

## 1. 考勤结果汇总分页查询

`POST /api/attendance/result/summary/page`

### 作用

查询员工考勤汇总结果，支持两种查询模式：按周期汇总和按日期范围聚合。只读已落表数据，不触发重算。

### 请求参数

| 字段 | 必填 | 说明 |
|------|------|------|
| periodCode | 否 | 考勤周期，格式 `yyyyMM`，与 `startDate/endDate` 至少传一种 |
| startDate | 否 | 开始日期，格式 `yyyy-MM-dd`，不传 periodCode 时必填 |
| endDate | 否 | 结束日期，格式 `yyyy-MM-dd`，不传 periodCode 时必填 |
| deptCode | 否 | 组织编码，支持父部门展开 |
| talentCode | 否 | 员工编码，模糊匹配 |
| talentName | 否 | 员工姓名，模糊匹配 |
| pageNo | 否 | 页码，默认 1 |
| pageSize | 否 | 每页条数，默认 20，最大 200 |

### 返回字段

| 字段 | 说明 |
|------|------|
| talentCode | 员工编码 |
| talentName | 员工姓名 |
| userId | 用户 ID |
| deptCode | 部门编码 |
| deptName | 部门名称 |
| periodCode | 周期编码 |
| startDate | 汇总开始日期 |
| endDate | 汇总结束日期 |
| lateCount | 迟到次数 |
| lateMinutes | 迟到分钟 |
| earlyLeaveCount | 早退次数 |
| earlyLeaveMinutes | 早退分钟 |
| absentCount | 旷工次数 |
| absentDays | 旷工天数 |
| supplementCount | 补签次数 |
| leaveDays | 请假天数 |
| tripDays | 出差天数，来源于考勤计算结果；跨日出差按覆盖日期每天计 1 |
| tripCount | 出差次数，按 `ip_db.business_trip.btId` 去重统计，口径：`isDeleted = 0`，不按 `wfStatus` 过滤 |
| overtimeHours | 加班小时 |
| actualWorkMinutes | 实际出勤分钟 |
| standardWorkMinutes | 标准出勤分钟（仅日期范围模式有值，周期模式返回 0） |
| calcTime | 计算时间 |
| calcVersion | 计算版本 |

### 处理规则

1. **双模式互斥**：`periodCode` 和 `startDate/endDate` 至少传一种，不能都不传。
2. **周期模式校验**：
   - `periodCode` 格式必须为 `yyyyMM`，否则报错。
   - 数据来源：`attendance_result_period_summary` 已落表周期汇总。
3. **日期范围模式校验**：
   - 不传 `periodCode` 时，`startDate` 和 `endDate` 必填。
   - `endDate` 不能小于 `startDate`。
   - 日期范围最大 31 天。
   - 数据来源：`attendance_result_day_detail` 按员工聚合 `SUM` 各指标。
4. **权限校验**：
   - 复用 `AttendanceCalcPermissionService.requireCalculator()`，只允许系统管理员和考勤员访问。
   - 普通员工不允许查汇总页。
   - 部门范围通过 `resolveQueryDeptCodes(ctx, deptCode)` 解析，父部门展开后与权限范围取交集。
5. **数据关联**：
   - 所有查询关联 `attendance_calc_cycle_state`，只查 `status IN ('已计算', 'calculated')` 的员工。
   - 关联 `ip_db.talent_person` 取员工姓名。
   - 关联 `ip_db.talent_organization` 取组织名称。
6. **分页**：默认 pageNo=1，pageSize=20，最大 pageSize=200。

## 2. 考勤结果汇总导出

`POST /api/attendance/result/summary/export`

### 作用

导出考勤结果汇总 Excel 文件，支持导出选中员工或按筛选条件导出全部。不做权限范围校验，token 由全局 `AuthInterceptor` 校验。

### 请求参数

| 字段 | 必填 | 说明 |
|------|------|------|
| exportMode | 是 | 导出模式：`selected` 或 `all` |
| selectedTalentCodes | 否 | 选中导出时的员工编码，逗号分隔，例如 `11318,10030`；`exportMode=selected` 时必填 |
| periodCode | 否 | 考勤周期，与 `startDate/endDate` 至少传一种 |
| startDate | 否 | 开始日期，格式 `yyyy-MM-dd` |
| endDate | 否 | 结束日期，格式 `yyyy-MM-dd` |
| deptCode | 否 | 组织编码 |
| talentCode | 否 | 员工编码 |
| talentName | 否 | 员工姓名 |

### 响应

返回 `ReturnInfo<ExportFileVO>`，后端生成 Excel 文件到磁盘，前端通过 `filePath` 下载。

| 字段 | 说明 |
|------|------|
| filePath | 前端下载路径，如 `/template/ip_attendance/attendance_result_summary/2026-05-20/1778234507579/考勤结果汇总_1778234507579.xlsx` |
| fileName | 文件名，如 `考勤结果汇总_1778234507579.xlsx` |

### 成功示例

```json
{
  "success": true,
  "data": {
    "filePath": "/template/ip_attendance/attendance_result_summary/2026-05-20/1778234507579/考勤结果汇总_1778234507579.xlsx",
    "fileName": "考勤结果汇总_1778234507579.xlsx"
  },
  "message": "ok",
  "messageType": 0
}
```

### Excel 列

| 列名 | 对应字段 |
|------|----------|
| 员工编码 | talentCode |
| 员工姓名 | talentName |
| 用户ID | userId |
| 部门编码 | deptCode |
| 部门名称 | deptName |
| 周期编码 | periodCode |
| 汇总开始日期 | startDate |
| 汇总结束日期 | endDate |
| 迟到次数 | lateCount |
| 迟到分钟 | lateMinutes |
| 早退次数 | earlyLeaveCount |
| 早退分钟 | earlyLeaveMinutes |
| 旷工次数 | absentCount |
| 旷工天数 | absentDays |
| 补签次数 | supplementCount |
| 请假天数 | leaveDays |
| 出差天数 | tripDays |
| 出差次数 | tripCount |
| 加班小时 | overtimeHours |
| 实际出勤分钟 | actualWorkMinutes |
| 标准出勤分钟 | standardWorkMinutes |
| 计算时间 | calcTime |
| 计算版本 | calcVersion |

### 处理规则

1. **exportMode**：必填，只允许 `selected` 或 `all`。
2. **selected 模式**：`selectedTalentCodes` 必填，逗号分隔解析后去重，按指定员工编码 IN 查询。
3. **all 模式**：按 `periodCode`/`startDate+endDate`/`deptCode`/`talentCode`/`talentName` 筛选条件导出全部，不分页。
4. **查询模式**：`periodCode` 和 `startDate/endDate` 至少传一种，规则与分页查询一致。
5. **不做权限范围校验**：不调用 `AttendanceCalcPermissionService`，不按 `deptScopes` 过滤。
6. **导出上限**：最大 10000 条，超出提示缩小筛选范围。
7. **日期范围模式**：`endDate` 不能小于 `startDate`，范围最大 31 天。
8. **数据来源**：周期模式查 `attendance_result_period_summary`；日期范围模式从 `attendance_result_day_detail` 聚合。均关联 `attendance_calc_cycle_state` 只导出已计算员工。
