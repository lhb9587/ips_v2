# 员工自助接口

---

## 1. 员工自助打卡记录查询

`POST /api/attendance/self/punch-record/list`

员工查询本人打卡记录。默认最近 30 天，每天一行，不分页。只查当前登录人，不支持查其他员工。

### 请求参数

| 字段 | 必填 | 类型 | 说明 |
|------|------|------|------|
| startDate | 否 | String | 开始日期，格式 yyyy-MM-dd，为空默认今天往前 29 天 |
| endDate | 否 | String | 结束日期，格式 yyyy-MM-dd，为空默认今天 |

日期规则：

- 都不传：最近 30 天（含今天）
- 只传 startDate：endDate 默认今天
- 只传 endDate：startDate 默认 endDate 往前 29 天
- endDate < startDate：参数错误
- 最大跨度 90 天，超过参数错误

不允许传入 talentCode、userId、deptCode，接口只查本人。

### 返回字段

| 字段 | 类型 | 说明 |
|------|------|------|
| seq | int | 序号，从 1 开始 |
| attendanceDate | String | 日期，yyyy-MM-dd |
| weekName | String | 星期，如 星期一 |
| onDutyTime | String | 有效上班卡时间，HH:mm:ss，无则为 null |
| offDutyTime | String | 有效下班卡时间，HH:mm:ss，无则为 null |
| offDutyNextDay | boolean | 下班卡是否跨天 |
| punchTimeText | String | 打卡时间展示文本，如 `09:02:15 / 18:11:03`、`09:02:15 / 01:20:00(+1)`、`缺上班卡 / 18:11:03` |
| punchCount | int | 当天原始打卡次数 |
| rawPunchTimes | List\<String\> | 当天全部原始打卡时间列表 |
| sourceText | String | 打卡来源，如 考勤机、手工导入、补签自动打卡 |
| statusText | String | 当天状态：正常、缺上班卡、缺下班卡、无打卡记录 |
| supplementTimeText | String | 补签时间展示，多个逗号分隔，无补签为空 |
| supplementItems | List\<Map\> | 补签明细，每项含 supplementTime 和 reasonName |
| actions | Object | 操作入口对象 |

### actions 字段

| 字段 | 类型 | 说明 |
|------|------|------|
| canSupplement | boolean | 是否显示"我要补卡"，固定 true |
| supplementAction | Map | 补卡入口参数，含 actionKey、attendanceDate、defaultTime |
| canLeave | boolean | 是否显示"我要请假"，固定 true |
| leaveAction | Map | 请假入口参数，含 actionKey、attendanceDate |
| canBusinessTrip | boolean | 是否显示"我要出差"，固定 true |
| businessTripAction | Map | 出差入口参数，含 actionKey、attendanceDate |

### punchTimeText 规则

| 场景 | 示例 |
|------|------|
| 正常上下班 | `09:02:15 / 18:11:03` |
| 下班跨天 | `09:02:15 / 01:20:00(+1)` |
| 缺上班卡 | `缺上班卡 / 18:11:03` |
| 缺下班卡 | `09:02:15 / 缺下班卡` |
| 无打卡 | `缺上班卡 / 缺下班卡` |

### statusText 规则

| 状态 | 条件 |
|------|------|
| 正常 | 有上班卡且有下班卡 |
| 缺上班卡 | 有下班卡但无上班卡 |
| 缺下班卡 | 有上班卡但无下班卡 |
| 无打卡记录 | 当天无任何打卡 |

## 2. 员工自助统计

`POST /api/attendance/self/statistics`

员工首页统计聚合接口，一次返回四块数据：待办审批、昨日出勤、当月出勤汇总、年假额度。只统计当前登录人，不支持查其他员工。

### 请求参数

无。全部按当前登录人统计。

### 返回字段

**todo（待办审批）：**

| 字段 | 类型 | 说明 |
|------|------|------|
| myWaitingLeaderApproveCount | int | 我提交的、当前还在等组长审批的单据数（仅统计 leave/overtime/supplement） |
| myPendingApproveCount | int | 当前登录人作为审批人待处理的单据数；非组长一般为 0 |

**yesterdayAttendance（昨日出勤）：**

| 字段 | 类型 | 说明 |
|------|------|------|
| attendanceDate | String | 昨日日期，如 `"2026-06-02"` |
| shiftName | String | 班次名称，如 `"白班"` |
| shiftStartTime | String | 班次开始时间，从 workTimeRange 解析，如 `"09:00"` |
| shiftEndTime | String | 班次结束时间，从 workTimeRange 解析，如 `"18:00"` |
| workTimeRange | String | 上班时间范围，如 `"09:00-18:00"` |
| actualWorkHours | BigDecimal | 实际出勤小时（actual_work_minutes / 60） |
| absentHours | BigDecimal | 旷工小时（absent_minutes / 60） |

**monthAttendance（当月出勤汇总）：**

| 字段 | 类型 | 说明 |
|------|------|------|
| month | String | 当月，如 `"2026-06"` |
| overtimeHours | BigDecimal | 当月加班小时合计 |
| exceptionCount | int | 当月异常次数（迟到 + 早退 + 缺上班卡 + 缺下班卡 + 旷工） |

**annualLeave（年假额度）：**

| 字段 | 类型 | 说明 |
|------|------|------|
| year | int | 当前年份 |
| leaveTypeCode | String | 法定年假类型编码，固定 `"JQLX0000010Y"` |
| leaveTypeName | String | 法定年假 |
| annualQuota | BigDecimal | 年假额度（actual_quota） |
| remainQuota | BigDecimal | 剩余额度（remain_quota） |
| frozenQuota | BigDecimal | 在途额度（frozen_quota） |

### 成功示例

```json
{
  "success": true,
  "data": {
    "todo": {
      "myWaitingLeaderApproveCount": 2,
      "myPendingApproveCount": 5
    },
    "yesterdayAttendance": {
      "attendanceDate": "2026-06-02",
      "shiftName": "白班",
      "workTimeRange": "09:00-18:00",
      "actualWorkHours": 8.00,
      "absentHours": 0.00
    },
    "monthAttendance": {
      "month": "2026-06",
      "overtimeHours": 12.50,
      "exceptionCount": 3
    },
    "annualLeave": {
      "year": 2026,
      "leaveTypeCode": "JQLX0000010Y",
      "leaveTypeName": "法定年假",
      "annualQuota": 5.00,
      "remainQuota": 3.00,
      "frozenQuota": 1.00
    }
  },
  "message": "ok",
  "messageType": 0
}
```

### 处理规则

1. 不传请求参数，全部按 `UserAuthContextHolder` 当前登录人统计。
2. 只读已落表数据，不触发考勤重算，不写库。
3. 出差不走审批中心，不计入审批在办统计。
4. 统计来源表：
   - 审批数量：`approval_instance`、`approval_task`、`approval_task_assignee`、`approval_biz_rel`
   - 昨日/当月出勤：`attendance_result_day_detail`
   - 年假额度：`attendance_leave_quota_account` + `attendance_leave_type_dict`
5. 空数据兜底：审批数量为 0、昨日无结果时返回日期其余为空、当月无结果时加班 0 异常 0、无年假时额度为 0。
