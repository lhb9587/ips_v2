# 假期类型接口

用于查询系统内置的固定假期类型字典。假期类型由后端固定写入数据库，不提供新增、删除、编辑、启停等人工维护能力。

---

## 1. 查询假期类型列表

获取当前所有启用的假期类型，按排序字段升序返回。

### 基本信息

| 项目 | 说明 |
|------|------|
| 请求路径 | `GET /api/leave/type/list` |
| Content-Type | `application/json` |
| 鉴权要求 | 需要登录（tokenID） |

### 请求参数

无。

### 响应体

#### 成功响应

```json
{
  "success": true,
  "data": [
    {
      "id": 1,
      "leaveTypeCode": "JQLX0000010Y",
      "leaveTypeName": "法定年假",
      "description": "固定假期类型，由后端内置",
      "sort": 10,
      "noQuota": false,
      "attachmentRequired": false
    },
    {
      "id": 2,
      "leaveTypeCode": "JQLX0000011Y",
      "leaveTypeName": "司龄假",
      "description": "固定假期类型，由后端内置",
      "sort": 11,
      "noQuota": false,
      "attachmentRequired": false
    },
    {
      "id": 3,
      "leaveTypeCode": "JQLX0000020Y",
      "leaveTypeName": "事假",
      "description": "固定假期类型，由后端内置",
      "sort": 20,
      "noQuota": true,
      "attachmentRequired": false
    }
  ],
  "total": null,
  "currPage": null,
  "message": "ok",
  "messageType": 0
}
```

#### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | Long | 主键 ID |
| `leaveTypeCode` | String | 假期类型编码，全局唯一固定编码 |
| `leaveTypeName` | String | 假期类型名称 |
| `description` | String | 说明 |
| `sort` | Integer | 排序号，升序 |
| `noQuota` | Boolean | 是否无预置额度假期（true：不需要额度即可申请，如事假、病假等） |
| `attachmentRequired` | Boolean | 提交请假时是否必须上传附件（true：必须上传，如婚假、产假等） |

#### 失败响应

```json
{
  "success": false,
  "data": null,
  "total": null,
  "currPage": null,
  "message": "缺少tokenID",
  "messageType": 20001
}
```

### 调用示例

```bash
curl -X GET "http://localhost:9091/api/leave/type/list?tokenID=177691146506299921"
```

## 2. 查询单个假期类型

根据假期类型编码查询单条记录。

### 基本信息

| 项目 | 说明 |
|------|------|
| 请求路径 | `GET /api/leave/type/{leaveTypeCode}` |
| Content-Type | `application/json` |
| 鉴权要求 | 需要登录（tokenID） |

### 路径参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `leaveTypeCode` | String | 是 | 假期类型编码，如 `JQLX0000010Y` |

### 响应体

#### 成功响应

```json
{
  "success": true,
  "data": {
    "id": 1,
    "leaveTypeCode": "JQLX0000010Y",
    "leaveTypeName": "法定年假",
    "description": "固定假期类型，由后端内置",
    "sort": 10,
    "noQuota": false,
    "attachmentRequired": false
  },
  "total": null,
  "currPage": null,
  "message": "ok",
  "messageType": 0
}
```

#### 失败响应

```json
{
  "success": false,
  "data": null,
  "total": null,
  "currPage": null,
  "message": "假期类型不存在: JQLX0000099Y",
  "messageType": 400
}
```

### 调用示例

```bash
curl -X GET "http://localhost:9091/api/leave/type/JQLX0000010Y?tokenID=177691146506299921"
```
