# 假期汇总表接口

基础路径：`/api/leave/report/summary`

统一返回结构：`ReturnInfo<T>`

公共规则：

| 规则 | 说明 |
|---|---|
| 请求方式 | 全部使用 `POST` |
| 参数方式 | 表单传参，不使用 `@RequestBody` |
| token | `tokenID` 通过 query 参数或请求头传入 |
| 分页返回 | `data` 直接返回列表，`total` 返回总数，`currPage` 返回当前页 |
| 权限范围 | 查询接口标注 `@ScopeAuthRequired` |
| 部门筛选 | 传入父部门时，按 `UserAuthContext.deptScopeTree` 展开子部门，再与当前用户 `deptScopes` 取交集 |

## 接口列表

| 序号 | 接口名 | 路径 | 是否完成 |
|---|---|---|---|
| 1 | 假期汇总分页查询 | `POST /api/leave/report/summary/page` | 已完成 |
| 2 | 假期汇总导出 | `POST /api/leave/report/summary/export` | 已完成 |

## 1. 假期汇总分页查询

`POST /api/leave/report/summary/page`

### 作用

按员工汇总指定日期范围内已通过请假单的假期使用量，按假期类型拆分为多列返回。

### 请求参数

| 字段 | 必填 | 说明 |
|---|---|---|
| startDate | 是 | 开始日期，格式 `yyyy-MM-dd` |
| endDate | 是 | 结束日期，格式 `yyyy-MM-dd` |
| deptCode | 否 | 组织编码，支持父部门展开 |
| talentCode | 否 | 员工编码模糊查询 |
| talentName | 否 | 员工姓名模糊查询 |
| leavePolicyCode | 否 | 假期制度编码 |
| pageNo | 否 | 页码，默认 `1` |
| pageSize | 否 | 每页条数，默认 `20`，最大 `200` |

### 返回字段

| 字段 | 说明 |
|---|---|
| talentCode | 员工编码 |
| talentName | 员工姓名 |
| deptCode | 部门编码 |
| deptName | 部门名称 |
| legalAnnualLeaveDays | 法定年假天数 |
| seniorityLeaveDays | 司龄假天数 |
| personalLeaveDays | 事假天数 |
| sickLeaveDays | 病假天数 |
| compOffHours | 调休假小时数 |
| marriageLeaveDays | 婚假天数 |
| maternityLeaveDays | 产假天数 |
| paternityLeaveDays | 陪产假天数 |
| breastfeedingLeaveDays | 哺乳假天数 |
| funeralLeaveDays | 丧假天数 |
| funeralTravelLeaveDays | 丧假路途假天数 |
| prenatalCheckLeaveDays | 孕检假天数 |
| miscarriageLeaveDays | 流产假天数 |
| nursingLeaveDays | 护理假天数 |
| childcareLeaveDays | 育儿假天数 |
| childcareLeave1Days | 育儿假1天数 |

### 返回示例

```json

  "data": [
    {

      "deptCode": "13401",

      "legalAnnualLeaveDays": 1.0,
      "seniorityLeaveDays": 0.0,
      "personalLeaveDays": 0.5,
      "sickLeaveDays": 0.0,
      "compOffHours": 2.0,
      "marriageLeaveDays": 0.0,
      "maternityLeaveDays": 0.0,
      "paternityLeaveDays": 0.0,
      "breastfeedingLeaveDays": 0.0,
      "funeralLeaveDays": 0.0,
      "funeralTravelLeaveDays": 0.0,
      "prenatalCheckLeaveDays": 0.0,
      "miscarriageLeaveDays": 0.0,
      "nursingLeaveDays": 0.0,
      "childcareLeaveDays": 0.0,

    }
  ],

  "currPage": 1,
  "message": "ok",
  "messageType": 0
```

### 处理规则

1. `startDate` 和 `endDate` 必填，格式为 `yyyy-MM-dd`。
2. `endDate` 不能小于 `startDate`。
3. 只统计 `attendance_leave_request.status = 已通过` 的请假单。
4. 数据来源为 `attendance_leave_request` 和 `attendance_leave_request_detail`。
5. 员工范围通过 `attendance_archive` 关联，且只统计有效考勤档案。
6. 部门名称来自 `ip_db.talent_organization`。
7. 员工姓名来自 `ip_db.talent_person`。
8. 普通员工不允许查询假期汇总。
9. 系统管理员、HR、考勤员、部门负责人允许查询。
10. 非系统管理员必须按当前用户部门权限范围过滤。

## 2. 假期汇总导出

`POST /api/leave/report/summary/export`

### 作用

导出假期汇总 Excel 文件，支持导出选中员工或按筛选条件导出全部。权限校验与分页查询一致。

### 请求参数

| 字段 | 必填 | 说明 |
|---|---|---|
| exportMode | 是 | 导出模式：`selected` 或 `all` |
| selectedTalentCodes | 否 | 选中导出时的员工编码，逗号分隔，例如 `11318,10030`；`exportMode=selected` 时必填 |
| startDate | 是 | 开始日期，格式 `yyyy-MM-dd` |
| endDate | 是 | 结束日期，格式 `yyyy-MM-dd` |
| deptCode | 否 | 组织编码，支持父部门展开 |
| talentCode | 否 | 员工编码 |
| talentName | 否 | 员工姓名 |
| leavePolicyCode | 否 | 假期制度编码 |

### 响应

返回 `ReturnInfo<ExportFileVO>`，后端生成 Excel 文件到磁盘，前端通过 `filePath` 下载。

| 字段 | 说明 |
|---|---|
| filePath | 前端下载路径，如 `/template/ip_attendance/leave_report_summary/2026-05-20/1778234507579/假期汇总表_1778234507579.xlsx` |
| fileName | 文件名，如 `假期汇总表_1778234507579.xlsx` |

### 成功示例

```json
{
  "success": true,
  "data": {
    "filePath": "/template/ip_attendance/leave_report_summary/2026-05-20/1778234507579/假期汇总表_1778234507579.xlsx",
    "fileName": "假期汇总表_1778234507579.xlsx"
  },
  "message": "ok",
  "messageType": 0
}
```

### Excel 列

| 列名 | 对应字段 |
|---|---|
| 员工编码 | talentCode |
| 员工姓名 | talentName |
| 部门编码 | deptCode |
| 部门名称 | deptName |
| 法定年假天数 | legalAnnualLeaveDays |
| 司龄假天数 | seniorityLeaveDays |
| 事假天数 | personalLeaveDays |
| 病假天数 | sickLeaveDays |
| 调休假小时数 | compOffHours |
| 婚假天数 | marriageLeaveDays |
| 产假天数 | maternityLeaveDays |
| 陪产假天数 | paternityLeaveDays |
| 哺乳假天数 | breastfeedingLeaveDays |
| 丧假天数 | funeralLeaveDays |
| 丧假路途假天数 | funeralTravelLeaveDays |
| 孕检假天数 | prenatalCheckLeaveDays |
| 流产假天数 | miscarriageLeaveDays |
| 护理假天数 | nursingLeaveDays |
| 育儿假天数 | childcareLeaveDays |
| 育儿假1天数 | childcareLeave1Days |

### 处理规则

1. **exportMode**：必填，只允许 `selected` 或 `all`。
2. **selected 模式**：`selectedTalentCodes` 必填，逗号分隔解析后去重，按指定员工编码 IN 查询。
3. **all 模式**：按 `startDate/endDate/deptCode/talentCode/talentName/leavePolicyCode` 筛选条件导出全部，不分页。
4. **日期校验**：`startDate` 和 `endDate` 必填，`endDate` 不能小于 `startDate`。
5. **权限校验**：与分页查询一致，标注 `@ScopeAuthRequired`。
   - 系统管理员、HR、考勤员、部门负责人允许导出。
   - 普通员工不允许导出。
   - 非系统管理员必须按当前用户部门权限范围过滤。
6. **导出文件**：后端生成 Excel 写入磁盘，返回 `ExportFileVO`（含 `filePath` 和 `fileName`），前端通过路径下载。
6. **导出上限**：最大 10000 条，超出提示缩小筛选范围。
7. **数据来源**：`attendance_leave_request` + `attendance_leave_request_detail`，只统计 `status=已通过` 的请假单。
