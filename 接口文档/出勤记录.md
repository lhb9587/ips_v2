# 出勤记录接口

基础路径：`/api/attendance/record`

统一返回结构：`ReturnInfo<T>`

公共规则：
- Content-Type：`application/x-www-form-urlencoded`
- tokenID 通过 query 参数或请求头传入
- 涉及数据权限的接口必须标注 `@ScopeAuthRequired`
- 分页接口返回时，`data` 直接放列表，`total` 放总数，`currPage` 放当前页

## 1. 出勤记录聚合分页查询

`POST /api/attendance/record/page`

按组织、姓名、日期范围查询员工逐日出勤聚合记录。

记录粒度为：`员工 + 出勤日期`。

该接口只读，不写库，不替代考勤计算结果。

### 查询条件

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| deptCode | String | 否 | 组织编码；为空时查当前用户权限范围内全部组织 |
| talentName | String | 否 | 员工姓名，模糊查询 |
| startDate | String | 否 | 开始日期，格式 yyyy-MM-dd；为空默认当天 |
| endDate | String | 否 | 结束日期，格式 yyyy-MM-dd；为空默认当天 |
| queryType | String | 否 | 查询方式，当前固定为 all |
| pageNo | Integer | 否 | 页码，默认 1 |
| pageSize | Integer | 否 | 每页条数，默认 20，最大 200 |

### 返回字段

| 字段 | 说明 |
|------|------|
| recordKey | 前端勾选用唯一键，建议 talentCode + "_" + attendanceDate |
| attendanceDate | 出勤日期 |
| talentCode | 员工编码 |
| talentName | 员工姓名 |
| deptCode | 组织编码 |
| deptName | 组织名称 |
| positionName | 职位名称 |
| punchRecords | 打卡记录摘要 |
| punchCount | 打卡次数 |
| punchSource | 打卡来源，预留字段 |
| supplementRecords | 补签卡记录摘要 |
| leaveTimeRange | 请假时间段 |
| leaveTypeName | 请假类型 |
| leaveDuration | 请假时长 |
| leaveStatus | 请假单状态 |
| businessTripTimeRange | 出差时间段 |
| businessTripDays | 出差天数 |
| businessTripStatus | 出差单状态 |
| overtimeTimeRange | 加班时间段 |
| overtimeHours | 加班时长 |
| overtimeStatus | 加班单状态 |

### 规则

1. 系统管理员可查全部。
2. HR、考勤员、部门负责人按权限范围查询。
3. 普通员工不进入后台出勤记录页。
4. `deptCode` 传父部门时，必须展开子部门后再和当前用户权限范围取交集。
5. `startDate` 不能大于 `endDate`。
6. 查询日期范围最大 31 天。
7. 只展示至少存在一种出勤业务数据的员工日期记录。
8. 打卡记录按时间升序拼接。
9. 请假、出差、加班只取已生效或审批通过数据。
10. 草稿、已废弃、已驳回单据不进入聚合结果。

## 2. 单员工单日出勤详情

`POST /api/attendance/record/detail`

查询某个员工某一天的出勤组成明细。

用于前端点击出勤记录列表某一行后查看完整明细。

### 请求参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| talentCode | String | 是 | 员工编码 |
| attendanceDate | String | 是 | 出勤日期，格式 yyyy-MM-dd |

### 返回字段

| 字段 | 说明 |
|------|------|
| talentCode | 员工编码 |
| talentName | 员工姓名 |
| deptCode | 组织编码 |
| deptName | 组织名称 |
| attendanceDate | 出勤日期 |
| punchRecords | 打卡明细列表 |
| supplementRecords | 补签卡明细列表 |
| leaveRecords | 请假明细列表 |
| businessTripRecords | 出差明细列表 |
| overtimeRecords | 加班明细列表 |

### 规则

1. 当前用户必须对该员工所属组织有权限。
2. 该接口只读，不写库。
3. 打卡、补签、请假、出差、加班分别返回明细列表。
