# 考勤设置查询接口

基础路径：`/api/attendance/setting`

统一返回结构：`ReturnInfo<T>`

公共规则：
- 所有接口均为只读，不写库
- 不加 `@ScopeAuthRequired`，token 校验通过即可访问
- 不分页
- Content-Type：`application/x-www-form-urlencoded`，参数通过表单提交
- tokenID 通过 query 参数传递，如 `?tokenID=xxx`

---

## 1. B1 查询固定考勤项目字段清单

`POST /api/attendance/setting/item/list`

返回固定考勤项目字段定义清单，用于考勤结果列表动态列配置。

### 请求

无请求参数。

### 响应

```json
{
  "success": true,
  "data": [
    {
      "itemCode": "attendance_date",
      "itemName": "考勤日期",
      "itemCategory": "base",
      "itemUnit": null,
      "valueType": "date",
      "detailVisible": true,
      "summaryVisible": true,
      "exportVisible": true,
      "sortNo": 10,
      "remark": "考勤结果所属日期，来源于考勤计算日期。"
    },
    {
      "itemCode": "late_count",
      "itemName": "迟到次数",
      "itemCategory": "exception",
      "itemUnit": "次",
      "valueType": "integer",
      "detailVisible": true,
      "summaryVisible": true,
      "exportVisible": true,
      "sortNo": 120,
      "remark": "迟到次数，后续由有效上班卡、班次和考勤制度异常规则计算。"
    }
  ],
  "total": null,
  "currPage": null,
  "message": "ok",
  "messageType": 0
}
```

### 响应字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| itemCode | String | 考勤项目编码 |
| itemName | String | 考勤项目名称 |
| itemCategory | String | 字段分类：base / schedule / punch / exception / bill / overtime / leave |
| itemUnit | String | 字段单位：天 / 分钟 / 小时 / 次，基础字段可为空 |
| valueType | String | 值类型：string / date / time / decimal / integer |
| detailVisible | Boolean | 是否用于明细模式展示 |
| summaryVisible | Boolean | 是否用于汇总模式展示 |
| exportVisible | Boolean | 是否允许导出 |
| sortNo | Integer | 展示排序号，数值越小越靠前 |
| remark | String | 字段口径备注 |

### 业务规则

1. 数据来源于 `AttendanceItemResolveService` 内存维护的固定清单，不查表
2. 只返回 `detailVisible=true OR summaryVisible=true OR exportVisible=true` 的项目
3. 按 `sortNo ASC` 排序

### itemCategory 分类

| 分类 | 说明 |
|------|------|
| base | 基础信息（考勤日期、员工编码、姓名、组织等） |
| schedule | 排班信息（班次名称、上下班时间） |
| punch | 打卡信息（第一段上班/下班时间） |
| exception | 异常信息（迟到次数/分钟、早退次数、旷工天数） |
| bill | 单据信息（补卡次数、出差时长） |
| overtime | 加班信息（调休OT1/OT2小时数、加班时长） |
| leave | 请假信息（病假/年假/事假/调休假/婚假时长） |

## 4. B4 查询固定班次列表

`POST /api/attendance/setting/shift/list`

查询启用中的班次列表，LEFT JOIN 取卡规则表带出规则名称。用于考勤档案默认班次下拉、排班列表编辑班次下拉、排班向导班次展示等场景。

### 请求

```
Content-Type: application/x-www-form-urlencoded

shiftCode=S&shiftName=标准&shiftType=standard
```

### 请求参数

| 字段 | 必填 | 类型 | 说明 |
|------|------|------|------|
| shiftCode | 否 | String | 班次编码，模糊查询 |
| shiftName | 否 | String | 班次名称，模糊查询 |
| shiftType | 否 | String | 班次类型，精确查询 |

### 响应

```json
{
  "success": true,
  "data": [
    {
      "shiftCode": "S001",
      "shiftName": "标准班",
      "shiftType": "standard",
      "fetchCardRuleCode": "FC001",
      "fetchCardRuleName": "默认取卡规则",
      "organizationCode": "100",
      "standardHours": 8.0,
      "overtimeCompensateMode": "time_off",
      "isDefault": 1,
      "remark": "",
      "status": 1
    }
  ],
  "total": null,
  "currPage": null,
  "message": "ok",
  "messageType": 0
}
```

### 响应字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| shiftCode | String | 班次编码 |
| shiftName | String | 班次名称 |
| shiftType | String | 班次类型 |
| fetchCardRuleCode | String | 取卡规则编码 |
| fetchCardRuleName | String | 取卡规则名称，LEFT JOIN 取卡规则表获取 |
| organizationCode | String | 组织编码 |
| standardHours | BigDecimal | 标准工时 |
| overtimeCompensateMode | String | 加班补偿方式 |
| isDefault | Integer | 是否默认班次 |
| remark | String | 备注 |
| status | Integer | 状态 |

### SQL 规则

1. 查询 `attendance_shift_dict`
2. 固定条件：`is_deleted = 0`、`status = 1`
3. `shiftCode` 有值时：`shift_code LIKE '%shiftCode%'`
4. `shiftName` 有值时：`shift_name LIKE '%shiftName%'`
5. `shiftType` 有值时：`shift_type = shiftType`（精确匹配）
6. LEFT JOIN `attendance_fetch_card_rule`：`fetch_card_rule_code = rule_code`，JOIN 条件带 `is_deleted = 0 AND status = 1`
7. 排序：`is_default DESC, shift_code ASC`

### 校验规则

| 条件 | 错误信息 |

| 规则不存在/已删除/已禁用 | 轮班规则不存在或已禁用 |

4. `shiftName` 使用 `COALESCE(shift.shift_name, detail.shift_name)` 优先取 JOIN 结果
5. 明细排序：`seq_no ASC`

## 8. B8 查询制度选择项

`POST /api/attendance/setting/policy-options`

查询启用中的考勤制度和假期制度选择项列表，用于考勤档案制度下拉等场景。

### 请求

```
Content-Type: application/x-www-form-urlencoded

keyword=标准&organizationCode=100
```

### 请求参数

| 字段 | 必填 | 类型 | 说明 |
|------|------|------|------|
| keyword | 否 | String | 关键字，匹配制度编码或名称（模糊查询） |
| organizationCode | 否 | String | 组织编码（精确查询，同时包含 organization_code 为空的通用制度） |

### 响应

```json
{
  "success": true,
  "data": {
    "attendancePolicies": [
      {
        "policyCode": "P001",
        "policyName": "标准考勤制度",
        "organizationCode": "100",
        "isDefault": 1,
        "fetchCardRuleCode": "FC001",
        "fetchCardRuleName": "默认取卡规则",
        "remark": ""
      }
    ],
    "leavePolicies": [
      {
        "policyCode": "LP001",
        "policyName": "标准假期制度",
        "organizationCode": "100",
        "isDefault": 1,
        "enablePriority": 1,
        "enableHalfDay": 0,
        "remark": ""
      }
    ]
  },
  "total": null,
  "currPage": null,
  "message": "ok",
  "messageType": 0
}
```

### attendancePolicies 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| policyCode | String | 考勤制度编码 |
| policyName | String | 考勤制度名称 |
| organizationCode | String | 组织编码 |
| isDefault | Integer | 是否默认制度 |
| fetchCardRuleCode | String | 取卡规则编码 |
| fetchCardRuleName | String | 取卡规则名称，LEFT JOIN 取卡规则表获取 |
| remark | String | 备注 |

### leavePolicies 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| policyCode | String | 假期制度编码 |
| policyName | String | 假期制度名称 |
| organizationCode | String | 组织编码 |
| isDefault | Integer | 是否默认制度 |
| enablePriority | Integer | 是否启用优先级 |
| enableHalfDay | Integer | 是否启用半天假 |
| remark | String | 备注 |

### SQL 规则

**考勤制度**（`attendance_policy`）：
1. 固定条件：`is_deleted = 0`、`status = 1`
2. `keyword` 有值时：`policy_code LIKE '%keyword%' OR policy_name LIKE '%keyword%'`
3. `organizationCode` 有值时：`organization_code IS NULL OR organization_code = organizationCode`
4. LEFT JOIN `attendance_fetch_card_rule`：带出取卡规则名称
5. 排序：`is_default DESC, policy_code ASC`

**假期制度**（`attendance_leave_policy`）：
1. 固定条件：`is_deleted = 0`、`status = 1`
2. `keyword` 有值时：`policy_code LIKE '%keyword%' OR policy_name LIKE '%keyword%'`
3. `organizationCode` 有值时：`organization_code IS NULL OR organization_code = organizationCode`
4. 排序：`is_default DESC, policy_code ASC`

### 业务规则

1. 同时查询考勤制度和假期制度，返回合并结果
2. `attendancePolicies` 和 `leavePolicies` 均不会返回 null，无数据时返回空数组
3. 不传参数时查全量启用制度
