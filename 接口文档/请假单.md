# 请假单

## 接口清单

| 序号 | 接口名 | 路径 | 是否完成 |
| ---- | ------ | ---- | -------- |
| 1 | 请假单列表分页查询 | `POST /api/leave/request/admin/page` | 已完成 |
| 2 | 请假单详情查询 | `POST /api/leave/request/admin/detail` | 已完成 |
| 3 | 请假单提交生效 | `POST /api/leave/request/admin/direct-pass` | 已完成 |
| 4 | 请假单反审批 | `POST /api/leave/request/admin/reverse-approve` | 已完成 |
| 5 | 请假单废弃 | `POST /api/leave/request/admin/abandon` | 已完成 |
| 6 | 请假单导出 | `POST /api/leave/request/admin/export` | 已完成 |

## 说明

后台管理端请假单查询接口，只做查询不做创建、编辑、删除。请假创建、额度校验、附件上传、半天规则计算等继续沿用员工自助端。

## 1. 请假单列表分页查询

`POST /api/leave/request/admin/page`

### 作用

后台管理端查询请假单列表，支持按权限范围筛选。

### 权限规则

- 系统管理员可查全部。
- HR、考勤员、部门负责人、组长按权限部门范围查询。
- 传 `deptCode` 时，展开父部门及全部子部门，再与当前用户部门权限范围取交集。
- 普通员工不开放后台入口，返回空列表。

### 请求参数

| 字段 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| `requestNo` | String | 否 | 单据编号模糊查询 |
| `talentCode` | String | 否 | 员工编码 |
| `talentName` | String | 否 | 姓名模糊查询 |
| `deptCode` | String | 否 | 组织编码，支持父部门筛选 |
| `leaveTypeCode` | String | 否 | 假期类型编码 |
| `requestStatus` | String | 否 | 单据状态：未提交、审批中、已通过、已退回 |
| `approvalStatus` | String | 否 | 审批状态：审批中、已通过、已退回 |
| `startDate` | String | 否 | 请假开始日期 |
| `endDate` | String | 否 | 请假结束日期 |
| `pageNo` | Integer | 否 | 页码，默认 1 |
| `pageSize` | Integer | 否 | 每页条数，默认 20，最大 200 |

### 返回字段

接口返回 `ReturnInfo<List<LeaveRequestAdminPageItemVO>>`，分页总数放在外层 `total`，当前页放在外层 `currPage`。

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| `leaveRequestId` | Long | 请假单ID |
| `requestNo` | String | 请假单号 |
| `talentCode` | String | 员工编码 |
| `talentName` | String | 员工姓名 |
| `deptCode` | String | 部门编码 |
| `deptName` | String | 部门名称 |
| `leaveTypeCode` | String | 假期类型编码 |
| `leaveTypeName` | String | 假期类型名称 |
| `startTime` | Date | 开始时间 |
| `endTime` | Date | 结束时间 |
| `leaveDuration` | BigDecimal | 请假时长 |
| `durationUnit` | String | 时长单位 |
| `requestStatus` | String | 单据状态 |
| `approvalStatus` | String | 审批状态 |
| `currentApproverName` | String | 当前审批人姓名（多人逗号分隔） |
| `applyTime` | Date | 申请时间 |
| `canDirectPass` | Boolean | 是否可提交生效 |
| `canReverseApprove` | Boolean | 是否可反审批 |
| `canAbandon` | Boolean | 是否可废弃 |

## 2. 请假单详情查询

`POST /api/leave/request/admin/detail`

### 作用

后台管理端查询请假单详情，包含基础信息、请假明细、审批信息和操作权限。

### 权限规则

- 系统管理员可查全部。
- HR、考勤员、部门负责人、组长按申请人部门范围查看。
- 普通员工不允许使用后台详情接口。

### 请求参数

| 字段 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| `leaveRequestId` | Long | 是 | 请假单ID |

### 返回字段

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| `leaveRequestId` | Long | 请假单ID |

## 5. 请假单废弃

`POST /api/leave/request/admin/abandon`

### 作用

后台考勤员废弃请假单。废弃后请假单状态变为"已废弃"，审批实例终止，冻结/已用额度释放/回退。

### 权限规则

- 系统管理员、HR、考勤员可操作。
- 普通员工不允许操作。

### 业务规则

- 允许废弃：未提交、已退回、审批中、已通过（未开始）。
- 禁止废弃：已废弃（不可重复）、已通过且已开始（startTime <= 当前时间）。
- 审批中废弃：释放冻结额度。
- 已通过未开始废弃：回退已用额度。
- 未提交废弃：无审批实例，直接更新状态。
- 操作人固定取当前登录人，不使用前端传值。

### 请求参数

| 字段 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| `leaveRequestId` | Long | 是 | 请假单ID（request_id） |
| `remark` | String | 否 | 废弃原因 |
| `operatorId` | String | 否 | 保留字段，不使用 |
| `operatorName` | String | 否 | 保留字段，不使用 |

### 返回字段

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| `leaveRequestId` | Long | 请假单ID |
| `requestNo` | String | 请假单号 |
| `beforeStatus` | String | 废弃前状态 |
| `afterStatus` | String | 固定"已废弃" |
| `approvalInstanceId` | Long | 审批实例ID（无则为 null） |
| `abandonActionId` | Long | 终止日志ID（无审批实例则为 null） |
| `quotaProcessed` | Boolean | 是否已处理额度 |

### 返回示例

```json
{
  "success": true,
  "data": {
    "leaveRequestId": 20260424090001,
    "requestNo": "QJ20260424001",
    "beforeStatus": "审批中",
    "afterStatus": "已废弃",
    "approvalInstanceId": 10001,
    "abandonActionId": 40002,
    "quotaProcessed": true
  },
  "total": null,
  "currPage": null,
  "message": "ok",
  "messageType": 0
}
```

## 6. 请假单导出

`POST /api/leave/request/admin/export`

### 作用

后台请假单列表导出，导出字段与列表分页查询一致。支持导出全部（按筛选条件）和导出选中记录。返回文件路径，不返回文件流。

### 权限规则

- 系统管理员可导出全部。
- HR、考勤员、部门负责人、组长只能导出权限部门范围内数据。
- 普通员工不允许导出。
- `SELECTED` 模式也必须套权限过滤，不能只按 ID 查。

### 请求参数

| 字段 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| `exportMode` | String | 是 | `ALL` 导出当前筛选条件下全部数据，`SELECTED` 导出选中记录 |
| `leaveRequestIds` | String | SELECTED 时必填 | 选中导出的请假单ID，逗号分隔，如 `1001,1002` |
| `requestNo` | String | 否 | 单据编号模糊查询 |
| `talentCode` | String | 否 | 员工编码 |
| `talentName` | String | 否 | 姓名模糊查询 |
| `deptCode` | String | 否 | 组织编码，支持父部门筛选 |
| `leaveTypeCode` | String | 否 | 假期类型编码 |
| `requestStatus` | String | 否 | 单据状态 |
| `approvalStatus` | String | 否 | 审批状态 |
| `startDate` | String | 否 | 请假开始日期 |
| `endDate` | String | 否 | 请假结束日期 |

### 导出字段

| 字段 | 中文列名 |
| ---- | -------- |
| `requestNo` | 请假单号 |
| `talentCode` | 员工编码 |
| `talentName` | 员工姓名 |
| `deptCode` | 组织编码 |
| `deptName` | 组织名称 |
| `leaveTypeName` | 假期类型 |
| `startTime` | 开始时间 |
| `endTime` | 结束时间 |
| `leaveDuration` | 请假时长 |
| `durationUnit` | 单位 |
| `requestStatus` | 单据状态 |
| `approvalStatus` | 审批状态 |
| `currentApproverName` | 当前审批人 |
| `applyTime` | 申请时间 |

### 返回字段

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| `filePath` | String | 前端访问路径 |
| `fileName` | String | 文件名 |
| `exportCount` | Integer | 导出条数 |

### 返回示例

```json
{
  "success": true,
  "data": {
    "filePath": "/template/ip_attendance/leave/request/2026-05-26/1779255974459/后台请假单导出.xlsx",
    "fileName": "后台请假单导出_1779255974459.xlsx",
    "exportCount": 120
  },
  "total": null,
  "currPage": null,
  "message": "ok",
  "messageType": 0
}
```
