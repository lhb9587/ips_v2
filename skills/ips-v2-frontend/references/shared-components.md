# 公共组件与页面复用

## 高频组件

- 列表页优先复用 `top-list-tool`、`list-search`、`grid-table`、`pagination`。
- 表格页默认参考 `src/views/case/trademark/index.vue` 一类页面骨架。
- 详情页优先看 `sidebar` 体系，不另造抽屉或详情面板。
- 工作台页面优先复用 `components/widgets/*`。

## 组件拆分

- 详情内容较多时，按基础信息、关联信息、附件、记录、操作区拆组件。
- 表单项很多或分步明显时，把不同分区拆成子组件。
- 列表页中搜索区、表格区、详情侧栏区职责分明时，优先复用既有组件，必要时补局部业务组件。
- 拆分后命名贴近业务语义，目录就近放置。

## 样式规则

- 优先使用项目已有 class、全局样式和 Element Plus 组件。
- 不新增全局主题或大范围覆盖 Element Plus 样式。
- 局部样式控制在当前页面或组件内。
- 无设计稿时，对齐同类型页面的间距、字号、操作区布局和状态展示。

## 时间与格式化

- 时间展示、解析和转换优先使用 `dayjs`。
- 不散落重复的 `Date` 手工拼接、字符串截取或多套时间格式化实现。
- 金额、百分比、数量等格式优先找项目已有工具函数或同类页面写法。
