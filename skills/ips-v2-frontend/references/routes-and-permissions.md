# 路由、菜单与权限

## 路由接入

- 新页面优先接入已有业务模块的 `src/router/modules/*.js`。
- 路由路径、文件目录、菜单项和权限标识保持同一业务命名。
- 新增模块路由后，检查 `src/router/routes.js` 是否需要聚合。
- 保持 `/v2` base 约定，不创建绕过既有路由体系的入口。

## 菜单接入

- 菜单结构优先参考 `src/components/menu.js` 中相邻业务模块。
- 菜单层级、图标、排序、权限字段沿用已有写法。
- 不凭空新增权限码或菜单结构；需要后端确认的内容先标记为待联调。

## 权限过滤

- 涉及权限时同时检查 `src/permission.js`、`allowRouterList` 和菜单 permissions。
- 不绕过项目已有登录、权限、路由守卫链路。
- 考勤和 HRM 相关页面需要特别确认人员范围、部门范围、分组范围和本人可见范围。

## 自查点

1. 直接访问路由是否符合权限预期。
2. 菜单入口是否出现并能正确跳转。
3. 无权限用户是否被过滤或拦截。
4. 刷新页面后路由是否仍可恢复。
